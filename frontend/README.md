# EKT AI Assistant — frontend

Автор UI: Moveath. Адаптивный интерфейс на HTML/CSS/JavaScript без зависимостей. Требуется Node.js 20+.

```powershell
cd frontend
npm start
```

Открыть http://localhost:5173. В отдельном терминале запустить существующий FastAPI backend на порту 8000 согласно его настройкам. UI работает и без backend, но запросы показывают сообщение о недоступности; вымышленные товары не отображаются.

`server.mjs` раздаёт только три файла frontend и проксирует `POST /api/chat` и `GET /health` в существующий backend. По умолчанию `BACKEND_URL=http://127.0.0.1:8000`; при необходимости переменную можно задать в терминале. Секреты frontend не нужны. Локальный сервер слушает только loopback; для публикации потребуется отдельная production-конфигурация.

Поддержаны история последних 12 сообщений, быстрые запросы, карточки с характеристиками, состояния загрузки/ошибки, сброс диалога и явное подтверждение позиций через `confirm_cart`. Поля контракта соответствуют `main.py`. Произвольный текст ответа отображается через `textContent`.

API корзины ekt.kz в текущем backend не подключён. Интерфейс сообщает только о подтверждении выбора и не обещает добавление в реальную корзину. Новое сообщение закрывает старое предложение подтверждения.

Проверка синтаксиса: `npm run check`. Для ручной проверки: отправить вопрос, проверить товары/ошибку, отправку Enter и Shift+Enter, отмену/подтверждение предложения и новый диалог. Проверить ширину 375px и desktop.
