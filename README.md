# ⚡ EKT.kz AI Assistant — Умный ИИ-консультант для интернет-магазина электротехники

> **Хакатон ekt.kz | Трек «Торговля»**  
> Интеллектуальный AI-ассистент с поиском по каталогу товаров, автоматическим подбором аналогов и защищённым механизмом добавления в корзину по правилу Must Have.

---

## 🎯 1. Проблема

Интернет-магазин электротехники **ekt.kz (ГК Электрокомплект)** ежедневно обрабатывает тысячи обращений клиентов. Анализ процессов выявил следующие проблемы:

- **Перегрузка менеджеров:** До 70% времени специалистов уходит на однотипные справочные вопросы (*«Есть ли кабель ВВГнг 3х2.5?», «Чем заменить автоматический выключатель на 16А?»*).
- **Длительное ожидание клиентов:** В пиковые часы клиенты ждут ответа менеджера, из-за чего снижается конверсия и падают продажи.
- **Сложность подбора:** Электротехнический каталог содержит тысячи узкоспециализированных параметров (сечения, IP-защита, ампераж, бренды), в которых покупателю трудно сориентироваться без консультации.
- **Риск случайных покупок:** При автокликах или ошибочных подсказках клиенты получают не тот товар, что влечет за собой возвраты.

---

## 💡 2. Наше решение

Мы разработали **умного ИИ-консультанта**, встроенного в веб-сайт ekt.kz. Бот берет на себя подбор электротехники, поиск альтернатив и помощь в оформлении заказа.

### ✨ Ключевые возможности:
1. **Точный поиск по каталогу ekt.kz:** Понимание профессиональных терминов, сечений, моделей и артикулов продукции.
2. **Умный подбор аналогов:** При отсутствии нужного товара бот мгновенно находит 100% совместимые альтернативы по техническим параметрам и цене.
3. **Безопасная корзина (Правило Must Have):** Товар добавляется в корзину **строго после явного и однозначного подтверждения клиента** (например, *"Да, добавь в корзину"*). Случайные действия полностью исключены.
4. **Интеграция с API ekt.kz:** Получение актуальных цен и остатков на складах в режиме реального времени.

## 🏗️ 3. Архитектура и Технологический Стек

```
┌──────────────────┐       ┌──────────────────────┐       ┌─────────────────────┐
│    Next.js UI    │ ────> │ FastAPI Backend (Py) │ ────> │   OpenAI GPT-4o     │
│   (Chat Widget)  │ <──── │  (REST / Async API)  │ <──── │  (Function Calling) │
└──────────────────┘       └──────────────────────┘       └─────────────────────┘
                                      │
                                      ▼
                           ┌──────────────────────┐
                           │   Каталог EKT.kz     │
                           │  (REST API / MySQL)  │
                           └──────────────────────┘
```

- **Backend:** Python 3.11+, FastAPI, Pydantic, Uvicorn
- **AI Core:** OpenAI GPT-4o + **Function Calling (Tools)** для строгого контроля бизнес-логики и выполнения правил корзины
- **Frontend:** Next.js 14, React, TailwindCSS, Lucide Icons
- **Database / Search:** PostgreSQL / In-Memory Index для быстрого поиска по каталогу ekt.kz

## 🚀 4. Инструкция по запуску для Жюри

### Предварительные требования
- Python 3.10+
- Node.js 18+
- Ключ OpenAI API (`OPENAI_API_KEY`)

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/your-team/ekt-ai-assistant.git
cd ekt-ai-assistant
```

### Шаг 2. Запуск Бэкенда (FastAPI)
```bash
cd backend

# Создание и активация виртуального окружения
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Создание файла конфигурации
cp .env.example .env
# Добавьте ваш OPENAI_API_KEY в файл .env

# Запуск сервера
uvicorn main:app --reload --port 8000
```
*Интерактивная документация Swagger доступна по адресу:* `http://localhost:8000/docs`

### Шаг 3. Запуск Фронтенда (Next.js)
```bash
cd ../frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```
*Чат-интерфейс доступен по адресу:* `http://localhost:3000`

## 🧪 5. Тестовые сценарии для проверки (Demo Guide)

| № | Действие пользователя | Ожидаемое поведение ИИ-ассистента |
|---|------------------------|-----------------------------------|
| 1 | *"Найди кабель ВВГнг 3х2.5"* | Бот находит товар в каталоге ekt.kz, выводит характеристики и актуальную цену. |
| 2 | *"Мне нужен автомат Schneider 16A" (нет на складе)* | Бот сообщает об отсутствии и предлагает релевантный аналогичный автомат в наличии. |
| 3 | *"Добавь этот кабель в корзину"* | Бот **НЕ добавляет сразу**, а запрашивает явное подтверждение: *"Вы подтверждаете добавление [Товар] в корзину?"* |
| 4 | Пользователь отвечает: *"Да"* | Бот вызывает функцию `add_to_cart` и товар отображается в корзине. |
| 5 | Пользователь отвечает: *"Нет"* | Операция отменяется, товар в корзину не добавляется. |
